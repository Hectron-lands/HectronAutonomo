API para desarrolladores

API REST y WebSocket de HECTRON Studio. Base URL: http://localhost:3000

Introducción

La API controla el agente local de PRISM Live Studio, gestiona el SaaS (planes, configuración) y proporciona comunicación en tiempo real vía WebSocket para el overlay y el cerebro del Leviatán.

Autenticación

Las rutas protegidas requieren el header X-Agent-Token con el valor configurado en AGENT_TOKEN del archivo .env. Si AGENT_TOKEN está vacío, la autenticación se desactiva (modo desarrollo).

# .env
AGENT_TOKEN=mi_token_secreto

# Request
curl -H "X-Agent-Token: mi_token_secreto" http://localhost:3000/status

Cambia la escena actual de PRISM Live Studio. Usado por el Leviatán para reaccionar con la emoción.

WS ws://localhost:3000/api/brain/ws

WebSocket bidireccional para comunicación en tiempo real entre el cerebro, el overlay y el agente.

// Conectar
const ws = new WebSocket('ws://localhost:3000/api/brain/ws');

// Autenticar
ws.send(JSON.stringify({ type: 'auth', token: 'mi_token' }));

// Cambiar escena
ws.send(JSON.stringify({ type: 'scene-change', scene: 'HAPPY_SCENE' }));

// Iniciar stream
ws.send(JSON.stringify({ type: 'start-stream' }));

// Detener stream
ws.send(JSON.stringify({ type: 'stop-stream' }));

// Acción autónoma
ws.send(JSON.stringify({
  type: 'autonomous-action',
  action: { type: 'scene-change', value: 'SAD_SCENE', confidence: 0.8 }
}));

// Mensajes recibidos
ws.onmessage = (e) => {
  const msg = JSON.parse(e.data);
  // scene-changed | stream-started | stream-stopped | error
};

SDK Python (Leviatán)

El Leviatán es un paquete Python que se usa como librería o standalone:

# Instalar dependencias
pip install -r leviatan/requirements.txt

# Usar como módulo
from leviatan import cerebro, memoria, voz, cuerpo, conocimiento, vision

# Generar respuesta con Gemini
texto, emocion = cerebro.pensar_respuesta(
    username="juan123",
    mensaje="¿cuál es el sentido de la vida?",
    es_conocido=False,
    interacciones=1,
    msj_anterior=""
)

# Recordar usuario
memoria.recordar_usuario("juan123", "¿cuál es el sentido de la vida?")

# Hablar
voz.hablar(texto)

# Cambiar expresión 3D
cuerpo.cambiar_expresion(emocion)

# Conocimiento real
texto, emo = conocimiento.saber("agujeros negros")

# Visión
texto, emo = vision.analizar_pantalla("Observa el stream")

# Arrancar todo
# python -m leviatan.main
